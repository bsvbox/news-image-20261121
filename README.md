One image for one day: this program paints a newspaper front page for Saturday 21 November 2026. It runs on Python 3.13 with no packages beyond the standard library, reaches for no network, and writes the same PNG bytes on every run.

The front page leads with Russian missiles coming down in Poland and NATO calling it a grave violation. Six more stories share the page: the double-tap strike on Kryvyi Rih, three Houthi missiles downed over Riyadh, Trump putting off the Iran strike decision, Bukele chasing a third term, NATO jets scrambled with Rutte bound for Warsaw, and a Trump–Xi–Putin summit that made history without a breakthrough.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The entry image lands at `out/entry.png`, 1024 by 1024 pixels.
