The World in One Page — 21 November 2026: a program that draws a one-page newspaper front page summing up the world's news of Saturday 21 November 2026 as a 1024x1024 PNG, pixel by pixel, using only the Python standard library. No network access, fully deterministic — two runs write byte-identical files.

Lead story: Russian missiles land in Poland, and NATO calls it a grave violation. Also on the page: the double-tap strike on Kryvyi Rih, Riyadh's air defences downing three Houthi missiles, Trump delaying the Iran strike decision, Bukele seeking a third term, NATO jets scrambled with Rutte heading to Warsaw, and the Trump–Xi–Putin summit ending without a breakthrough.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
